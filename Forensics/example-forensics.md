# Forensics - مثال بسيط
- القسم: Forensics
- اسم المُلخّص: Lina
- التاريخ: 2026-08-16
- مصدر التحدي: مختبر داخلي
- الصعوبة: Easy
- الوسوم: forensics, stego

ملخص سريع
- ملف صورة يحتوي رسالة مخفية. استخدمت أدوات الستيجنو لاستخراجها.

النهج والخطوات
1. فحص الملف باستخدام `exiftool` لمعرفة أي معلومات ميتاداتا.
2. استخدمت `steghide` أو `stegsolve` لاستخراج النص.

أوامر
```bash
exiftool image.png
steghide extract -sf image.png
```

الحل النهائي
- استخرجت: `flag{hidden_message}`

ملاحظات
- راجع أساسيات الستيجنو وأنواع الحشو المختلفة.
