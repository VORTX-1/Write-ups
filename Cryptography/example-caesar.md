# Caesar Cipher - مثال
- القسم: Cryptography
- اسم المُلخّص: Ali
- التاريخ: 2026-08-16
- مصدر التحدي: مختبر داخلي
- الصعوبة: Easy
- الوسوم: crypto, caesar, shift

ملخص سريع
- الشيفرة كانت قيصر بتحريك 3 حروف. المطلوب استعادة النص الأصلي.

النهج والخطوات
1. لاحظت أن النص يحتوي على أحرف a-z فقط: `khoor zruog`
2. جربت إزاحة 3 للوراء باستخدام سكربت بيثون:

أوامر
```bash
python3 - <<'PY'
s="khoor zruog"
for k in range(1,26):
    print(k, ''.join(chr((ord(c)-97-k)%26+97) if c.islower() else c for c in s))
PY
```

الحل النهائي
- عند k=3 حصلت على: "hello world" -> لا توجد flag صريحة لكن نفس الفكرة تطبق لاستخراج flag.

ملاحظات
- استخدمت أسلوب brute-force لأن مجموعة التحويلات صغيرة.
