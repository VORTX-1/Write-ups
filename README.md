# CTF Write-ups (لفريقنا)

هدف المستودع
- تجميع رايت-أبس خاصة بالفريق لتعليم المبتدئين والحفاظ على حلولنا للمسابقات والتمارين.
- تنظيم الحلول ضمن 4 أقسام رئيسية: Cryptography, Web, Reverse Engineering, Forensics.

كيفية الاستخدام
1. اختر القسم المناسب (مجلد).
2. انسخ القالب `TEMPLATE_WRITEUP.md`، واملأه باللغة العربية (أو الإنجليزية إن أردت).
3. احفظ الملف باسم واضح حسب قواعد التسمية (انظر CONTRIBUTING.md).
4. افتح فرع جديد، ارفع التغييرات، وافتح Pull Request.
5. سيقوم عضو آخر بمراجعة المحتوى ثم الدمج.

قواعد عامة
- هدف النشر: شرح خطوات الحل لا الغش — اكتب تعليقات تعليمية واذكر الأدوات والأوامر.
- لا تنشر بيانات حساسة أو مفاتيح حقيقية من مسابقات حية إن كانت محظورة.
